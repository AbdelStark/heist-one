# Changelog

All notable changes to HEIST//ONE are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-17

### Added

- Playable one-level browser stealth game with a deterministic 30 Hz server
  simulation and a React/Phaser client.
- Six guards driven through a narrow `DecisionEngine` contract, with both live
  Jev and deterministic scripted implementations.
- Batched `Noul`, `Score`, and `Choice` judgments plus server-side legality,
  policy, deadline, and freshness checks.
- Decision Lens UI and append-only JSONL evidence traces.
- Unit, contract, and browser-controlled full-heist acceptance tests.
- Reproducible Remotion launch film built from a verified live Jev extraction.
